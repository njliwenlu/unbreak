## How the app uses them

The Midair level shows the source-speed excerpt with the credit above, and Argon reconstructs the ramp geometry from it in car-length units. Absolute scale (car length 0.45 m) and approach speed (7 m/s) are labeled assumptions/calibrations, not measurements from the footage.
